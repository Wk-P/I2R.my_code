# 2. 标准答案：ILP

## 它是干什么的

ILP（整数线性规划）把问题写成数学式子，交给求解器（PuLP + CBC）去算，能保证拿到**最优解**。
在本项目里它是"满分答案"，用来算 RL 的 gap。

## 变量

- x_mn = 1 表示服务 m 放在 ECU n 上，否则 0。
- y_n = 1 表示 ECU n 被用上了。

约束：每个服务恰好放一个 ECU；每个 ECU 负载 ≤ 容量；冲突的两个服务不能在同一个 ECU 上；用了才能放。

## 难点：目标是个"除法"

AR = 总利用率 ÷ 用到的 ECU 数，是分数，线性规划没法直接最大化分数。
所以用 **Dinkelbach 方法**，把"最大化分数"变成"反复解几次普通问题"：

1. 先猜一个 AR 值 q（比如 0）。
2. 解一个普通 ILP：最大化 总利用率 − q × ECU 数。
3. 用这次的解算出真实 AR，作为新的 q。
4. 如果 q 几乎不再变化（变化 < 1e-6，说明找不到比 q 更好的解了），停；否则回到第 2 步。

平均约 **3 次**就收敛（实测 3.06 次）。代码：`src/shared/ilp_utils.py` 的 `solve_ilp_max_ar`。

## 它的问题：慢

单线程 CPU 上，每个实例平均要 **0.5 ~ 3 秒**（LT 最慢，约 3.2 秒），实例越大越慢。
RL 一个实例只要几十毫秒（第 8 篇）。
