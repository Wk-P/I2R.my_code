# 测试实例耗时：结构感知网络 vs ILP

- 生成时间：2026-10-08 10:28:21；脚本 `src/scripts/bench_time.py`；总耗时 3.3 分钟。
- 实例：种子 1 测试集（每场景 400 个，与训练报告同一划分），逐个实例计时，单位 ms/实例。
- 网络：v4.4.3 5M 种子 1 模型（`logs/v4.4.3/manifest.json`），CPU 单线程（`torch.set_num_threads(1)`），确定性策略；「整条 episode」= reset + 每步动作掩码 + 前向 + 环境 step，直到放完或 EXIT；「仅前向」= 其中网络前向（含 SB3 predict 开销）的累计。先热身 5 个 episode。
- ILP：`solve_ilp_max_ar`（Dinkelbach，PuLP + CBC 默认单线程），计时包含建模与全部迭代，与 v4.3.1.7 的口径相同。12 个实例并行求解，每个实例单独计时。
- 计时时机器上同时有 9 个 GPU 训练进程（各占约 1 个 CPU 核）；56 核未占满，单个实例的计时基本不受影响，但不是完全空载。
- 加速比 = ILP 平均耗时 / 网络平均耗时；中位数加速比 = ILP 中位数 / 网络中位数。
