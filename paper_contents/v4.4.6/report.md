# v4.4.6 显式全局特征：global token 加入 σ_util

- 生成时间：2026-10-08 19:12:53
- 唯一改动：global token 加入已开启 ECU 利用率的标准差 σ_util = sqrt(mean_j∈on (u_j/c_j − AR_t)²)，乘 2 归一化到 [0, 1]（`--glob-std`）。global token 自 v4.4.3 起已显式包含 AR_t 与未放置服务占比 (M − t)/M（`src/paper_rl/graph_net.build`），因此不重复加入；加入后 global token 同时描述任务进度、当前目标水平和资源分配的离散程度。
- 其余与 v4.4.5 定稿配置完全相同：结构感知网络、lr 3e-4、熵系数 0.005、GAE λ = 0.95、ar_pen 奖励、γ = 1、EXIT、需求降序、GPU、1M 步。
- 基线 = v4.4.5 在 GPU 上训练的三种子基线（种子 1：`logs/v4.4.5_pilot`，种子 2、3：`logs/v4.4.5_seeds`），直接复用，没有重新训练；新模型 manifest：`logs/v4.4.6/manifest.json`。
- 每个模型都在它自己训练种子的测试集上评估；相对 gap 先逐种子计算再取平均；表中为三种子均值 ± 样本标准差。
- 第 1–5 步 regret 与选中最优的比例来自 `src/scripts/diag_regret.py`（各种子测试集前 400 个实例）。参照噪声（v4.4.5）：同配置三种子的相对 gap SD 为 0.4–0.7pp。
