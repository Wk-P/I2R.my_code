# 各算法伪代码（v4.2.0）

本文档给出 v4.2.0 最优模型合集中 6 个算法的伪代码，每个算法都按**该格模型实际训练时的代码**编写（各格训练代码版本见 `formula.md` 开头的表）。场景间有差异的地方在伪代码中用 `if 场景 == ...` 标出。公式见 `formula.md`。

---

## 0. 公共部分

```
# 一个 episode（训练与评估共用）
function RUN_EPISODE(实例, 策略):
    ECU 剩余容量 R[j] ← e_j ;  已放置集合 ← 空 ;  valid ← 0 ;  total_u ← 0
    服务队列 ← 实例中的服务（若该格模型做降序重排，则按需求量从大到小排序）
    for t = 0 .. M-1:
        s_t ← OBS()                                    # 观测，见 formula.md 3.2
        a_t ← 策略(s_t)                                 # 各算法不同，见下文
        v_cap  ← (R[a_t] < n_t)
        v_conf ← (ECU a_t 上已有与服务 t 同一冲突集的服务)
        执行放置: R[a_t] ← R[a_t] - n_t                  # 容量违规也照常执行（Repair-PPO 除外）
        if 合法: valid ← valid + 1
        total_u ← total_u + u_t                         # 违规时是否计入因算法而异
        AR ← total_u / (已启用 ECU 数)
        r_t ← 非终端步奖励（各算法不同）
    r_{M-1} ← R_term                                    # 终局奖励替代最后一步的非终端奖励
    return AR, valid, 违规计数

# 终局奖励基础形式
function R_TERM(AR, valid, 是否有违规):
    if 无违规: return M * (2*AR - 1)
    else:      return -M * (1 - valid / M)
```

## 1. PPO（无约束基线）

训练代码 v4.0.0（三场景）。服务按数据集原始顺序处理；观测中没有 `svc_valid_ecus`。

```
for t = 0 .. M-1:
    a_t ← π_θ(s_t)                       # 全部 N 个 ECU 都可选
    记录 v_cap, v_conf（不惩罚、不阻止）
    执行放置；u_t 无论是否违规都计入 AR
    r_t ← 0
r_{M-1} ← R_TERM(AR, valid, 是否有违规)
```

训练：标准 PPO-Clip（见第 7 节）。

## 2. Mask-PPO（硬掩码）

训练代码 v4.0.0（三场景）。用 MaskablePPO，环境由 ActionMasker 包装。

```
function ACTION_MASK(t):
    m[j] ← (R[j] >= n_t) AND (放到 j 不冲突)          # 容量 + 冲突
    if 场景 == LT AND m 不全为 0:
        m'[j] ← m[j] AND NOT LETHAL_AFTER(j)           # 一步前瞻
        if m' 不全为 0: m ← m'
    return m

function LETHAL_AFTER(j):                              # 放到 j 后是否有后续服务无处可放
    假设把服务 t 放到 j
    for 每个后续服务 i > t:
        if 没有任何 ECU 同时满足容量与冲突约束: return True
    return False

for t = 0 .. M-1:
    m ← ACTION_MASK(t)
    if m 全为 0:
        a_t ← 在 N 个 ECU 中均匀随机（MaskablePPO 对全部 logit 置 -1e8 的结果）
        # 该步必然违规；评估时直接结束 episode，记为失败
    else:
        a_t ← π_θ(s_t | 仅 m=1 的 ECU)                  # 不可行动作概率为 0
    执行放置；违规的放置 u_t 记为 0
    r_t ← 0
if 无违规:
    if 场景 == LT: r_{M-1} ← M * [(1-w) + w*(2*AR - 1)]   # w: 训练过程中 0 → 1 线性增加
    else:          r_{M-1} ← M * (2*AR - 1)
else:
    r_{M-1} ← -M * (1 - valid / M)
```

训练：PPO-Clip，策略分布先经过掩码；LT 的熵系数从 0.02 线性退火到 0.002。

## 3. Lagrange-PPO（无掩码，惩罚 + 对偶变量）

训练代码：LT v4.0.0，EQ v4.1.0，GT v4.1.0.1。动作空间不受限；λ 作为一维特征 clip(λ/λ_max, 0, 1) 进入观测。

```
# 环境：每一步
for t = 0 .. M-1:
    a_t ← π_θ(s_t)                                     # 全部 N 个 ECU 都可选
    计算 v_cap, v_conf；执行放置；u_t 照常计入 AR
    if 场景 == LT:
        r_t ← 0
    elif 场景 == EQ:
        r_t ← u_t / (已启用 ECU 数) - 2*v_cap - (λ + 0.2)*v_conf
    elif 场景 == GT:
        r_t ← -2*v_cap - (λ + 0.2)*v_conf
r_{M-1} ← R_TERM(AR, valid, 是否有违规)

# 训练回调：对偶上升（每个 episode 结束时）
ν_ep ← (容量违规次数 + 冲突违规次数) / M
把 ν_ep 放入长度为 W 的滑动窗口
if 已完成 episode 数 >= E_w AND 距上次更新已过 W 个 episode:
    λ ← clip(λ + η * (窗口均值 - 0), 0, λ_max)
    把 λ 同步到所有并行环境
# (λ_0, η, λ_max, W, E_w):
#   LT (0, 3e-4, 2.0, 20, 20000)   EQ (0.5, 0.01, 5.0, 200, 0)   GT (0.1, 0.005, 5.0, 20, 5000)

# 评估：λ 固定为训练结束时的值
```

训练：PPO-Clip，熵系数 0.005。

## 4. Repair-PPO（最佳适应修复）

训练代码 v4.1.0（三场景）。

```
function BEST_FIT_REPAIR(t):
    V ← { j : R[j] >= n_t AND 放到 j 不冲突 }
    if V 为空: return None
    return argmax_{j∈V} n_t / e_j                      # 放进去后利用率最高的合法 ECU

repaired_any ← False
for t = 0 .. M-1:
    a_t ← π_θ(s_t)                                     # 全部 N 个 ECU 都可选
    if v_cap OR v_conf:
        a' ← BEST_FIT_REPAIR(t)
        if a' is None:
            return 奖励 -M，episode 立即结束              # 修复失败
        a_t ← a' ;  repaired_any ← True ;  修复触发计数 +1
        r_t ← -0.1
    else:
        r_t ← 0
    执行放置（一定合法）；valid ← valid + 1
if 场景 == LT:
    r_{M-1} ← (repaired_any ? 0 : M * (2*AR - 1))
else:  # EQ, GT
    r_{M-1} ← M * (2*AR - 1)
```

训练：PPO-Clip，熵系数 0.001。

## 5. DQN

训练代码 v4.1.0（三场景）。无掩码、无修复。

```
# 环境：每一步
for t = 0 .. M-1:
    a_t ← ε-greedy(Q_θ, s_t)                          # 评估时 ε = 0
    执行放置（违规也照常执行，episode 继续）；违规的放置 u_t 记为 0
    R_t ← 0
    P_t ← 2*v_cap + 2*v_conf                          # 单步惩罚，三个场景相同
    r_t ← R_t - P_t
r_{M-1} ← R_TERM(AR, valid, 是否有违规)

# 训练
初始化 Q_θ, Q_θ⁻ ← Q_θ, 回放池 D
for 环境步 = 1 .. 5e6:
    ε 在前 f 比例的步数内从 1 线性降到 0（f: LT/GT 0.5，EQ 0.1）
    与环境交互，把 (s, a, r, s', done) 存入 D
    if 已过 learning_starts AND 环境步 % 4 == 0:
        从 D 采样 64 条
        y ← r + γ(1-done) * max_a' Q_θ⁻(s', a')
        用 Huber(Q_θ(s,a) - y) 做一次梯度更新
    每 500 步: Q_θ⁻ ← Q_θ
```

## 6. DDQN

训练代码 v4.1.0（三场景）。环境、奖励、探索、回放与 DQN 完全相同，只有目标值不同：

```
a* ← argmax_a' Q_θ(s', a')                             # 在线网络选动作
y  ← r + γ(1-done) * Q_θ⁻(s', a*)                      # 目标网络评估该动作
用 Huber(Q_θ(s,a) - y) 做一次梯度更新
```

## 7. PPO 系列的训练循环

PPO、Mask-PPO、Lagrange-PPO、Repair-PPO 共用：

```
for 迭代 = 1 .. 5e6 / (n_steps * 并行环境数):
    用 π_θ 在并行环境中各采集 n_steps 步（Mask-PPO 按掩码采样）
    用 GAE 计算优势 Â_t 与回报 R̂_t
    for epoch = 1 .. n_epochs:
        for 每个 minibatch:
            Â 在 minibatch 内标准化
            ρ ← π_θ(a|s) / π_θ_old(a|s)
            L_clip ← mean( min(ρÂ, clip(ρ, 1-ε, 1+ε)Â) )
            L ← -L_clip + 0.5 * mean((V_θ(s) - R̂)²) - c_e * mean(熵)
            梯度更新（梯度范数裁剪 0.5）
    （Mask-PPO LT：按训练进度更新 c_e 与课程权重 w；Lagrange-PPO：λ 由回调更新）
```

## 8. 评估（论文结果所用）

```
for 每个模型（每个种子一个）:
    for 该种子测试集中的每个实例（400 个）:
        跑 1 次 RUN_EPISODE，策略取确定性动作
        （Mask-PPO：无合法 ECU 时结束；Lagrange-PPO：λ 固定为训练结束值）
        success ← (valid == M) 且执行的放置无违规
        记录 AR、是否成功、是否出现容量 / 冲突违规、（Repair-PPO）是否触发修复、耗时
    求该模型的各项均值
对同一格的各种子模型求均值 ± 样本标准差
```

## 9. 约束处理方式一览

| 算法 | 约束处理时机 | 执行的放置能否违规 | 非终端步奖励 |
|---|---|---|---|
| PPO | 不处理，只记录 | 能 | 0 |
| Mask-PPO | 采样前掩码（LT 加一步前瞻） | 只在无合法 ECU 时 | 0 |
| Lagrange-PPO | 惩罚 + 对偶变量 | 能 | LT 0；EQ 利用率增益 + 容量惩罚 + λ 冲突惩罚；GT 容量惩罚 + λ 冲突惩罚 |
| Repair-PPO | 执行前修复 | 不能（修复失败则提前终止） | -0.1 × 是否修复 |
| DQN / DDQN | 单步惩罚 | 能 | r_t = R_t - P_t，P_t = 2·容量违规 + 2·冲突违规 |
