# v4.2.0 — 最优模型合集（论文最终结果）

v4.2.0 不重新训练，而是把每个（场景, 算法）格子里结果最好的那批已训练模型挑出来组成一个混编集合，用统一的评估口径重新评估，并做 ILP vs RL 的求解耗时测试。

## 评估口径

- 每个测试实例只跑一次，策略取确定性动作（`EVAL_BEST_OF_N = 1`，`deterministic=True`）。best-of-8 已全面停用（见 `../v4.1.0_changelog.md`"评估口径统一"一节）。
- 每个模型在它自己种子对应的测试集上评估（400 个实例）；表中数值是各种子的均值 ± 样本标准差（ddof=1）。
- 训练代码版本之间只有 reward 不同，评估时用到的观测和状态转移一致，因此全部用当前 `scenarios/` 代码评估。

## 求解耗时（ms / 测试实例，单线程 CPU）

| 方法 | LT（M=15） | EQ（M=10） | GT（M=10） |
|---|---|---|---|
| ILP（Dinkelbach + CBC） | 180.7 ± 213.6 | 45.0 ± 7.3 | 60.3 ± 4.6 |
| PPO | 8.86（20.4×） | 6.06（7.4×） | 5.98（10.1×） |
| Mask-PPO | 17.89（10.1×） | 10.70（4.2×） | 10.10（6.0×） |
| Lagrange-PPO | 10.12（17.9×） | 6.29（7.2×） | 6.56（9.2×） |
| Repair-PPO | 10.02（18.0×） | 6.79（6.6×） | 7.13（8.5×） |
| DQN | 6.67（27.1×） | 4.39（10.3×） | 4.49（13.4×） |
| DDQN | 6.70（27.0×） | 4.44（10.2×） | 4.46（13.5×） |

括号内为相对 ILP 的加速比。ILP：种子 1 测试集 400 个实例逐个求解，均值 ± 实例间标准差。RL：每个种子模型跑完自己的 400 个测试实例求每 episode 平均耗时，再在种子间取平均；计时包含环境计算（reset/step/动作掩码）与网络推理，预热 5 个 episode 后开始计时。

## 与 v4.1.0.2 文档的主要差别

`../v4.1.0.2/` 的公式与伪代码描述的是 v4.1.0.2 定案代码，不对应 v4.2.0 的模型。以 v4.2.0 文档为准，主要差别：

- Lagrange-PPO 的 EQ/GT 模型训练时 λ 进入了逐步奖励（EQ：利用率增益 + 容量惩罚 + λ 冲突惩罚；GT：容量惩罚 + λ 冲突惩罚），只有 LT 是逐步奖励为 0。
- λ 的更新依据是容量与冲突违规的合计率，三个场景超参数不同。
- Repair-PPO 的 LT 模型：触发过修复则终局奖励为 0；EQ/GT 跑满全程一律 M(2AR−1)。
- Mask-PPO 的一步前瞻和课程权重 w 只在 LT；无合法 ECU 时掩码全 0，动作在 N 个 ECU 中均匀随机。
- GT 的 DQN/DDQN 容量违规即终止（奖励 −M）。
- PrunedPPO 的负优势权重为 1，等同标准 PPO。
