# 测试实例耗时与 gap：结构感知网络 vs ILP

- 生成时间：2026-10-11 14:04:22；脚本 `src/scripts/bench_infer.py`；总耗时 48.8 分钟。
- 模型：v4.4.16 结构感知 Mask PPO（5 万实例，10M）（`logs/v4.4.16/manifest.json`，key `mask_ppo_pool10m`），种子 1, 2, 3；每个模型在它自己训练种子的 400 个测试实例上计时，ILP 在同一批实例上计时，因此耗时与 gap 一一对应。
- 网络：CPU 单线程（`torch.set_num_threads(1)`），确定性策略；「整条 episode」= reset + 每步动作掩码 + 前向 + 环境 step；「仅前向」= 其中网络前向（含 SB3 predict 开销）的累计；先热身 5 个 episode。
- ILP：`solve_ilp_max_ar`（Dinkelbach，PuLP + CBC 默认单线程），计时包含建模与全部迭代；12 个实例并行求解，每个实例单独计时。
- 计时时机器上同时有 GPU 训练进程（各占约 1 个 CPU 核）；56 核未占满，但不是完全空载。加速比 = ILP 耗时 / 网络耗时（平均 / 中位数）。
