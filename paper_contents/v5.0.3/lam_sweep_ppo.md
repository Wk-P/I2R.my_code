# v5.0.3 λ_max 扫描（PPO）

- lagrange_ppo、种子 1、3M 步，λ_max ∈ {1, 2, 5}；测试集 400 实例确定性评估。
- 有效 gap：有违约的实例按 AR = 0 计，1 − 平均 AR / 平均 ILP AR。
- 选定规则（违约优先）：三场景平均无违约比例最高；与最高值相差 0.5 个百分点以内视为持平，持平时选三场景平均有效 gap 更低的。3M 步的扫描对 gap 说明有限，违约的权重更高。
