# v4.3.1.10 — 训练步数 5M → 10M

v4.3.1 的子版本（tag `v4.3.1.10`）。

## 1. 动机

- v4.3.1.6 的训练曲线显示 PPO 系列到 5M 步仍在上升（最后 1M 步成功回合 AR 在 EQ/GT 又涨了 1.2~1.5 个百分点）；DQN/DDQN 的 Maskable / Repair 已走平。
- 贪心基线（`src/paper_rl/greedy.py`：可行 ECU 中先选已开的，再选需求/容量最大的）与最好的 RL（Maskable-PPO，5M）对比，AR 与 ILP AR 都在各自成功的实例上平均，AR gap = ILP AR − AR：

  | 场景 | 贪心 AR / ILP AR / AR gap | Maskable-PPO AR / ILP AR / AR gap | 成功率（贪心 vs PPO） |
  |---|---|---|---|
  | LT | 0.7269 / 0.8978 / 0.1708 | 0.7216 / 0.8875 / 0.1659 | 58.0% vs 86.9% |
  | EQ | 0.7107 / 0.8566 / 0.1459 | 0.7085 / 0.8567 / 0.1482 | 99.8% vs 99.8% |
  | GT | 0.7675 / 0.9093 / 0.1418 | 0.7576 / 0.9093 / 0.1517 | 100% vs 100% |

  EQ/GT 上 RL 的 AR gap 比贪心大 0.002~0.010；RL 的明确优势只在 LT 成功率。
- 本版本回答：步数翻倍后，RL 的 AR 能否超过贪心。

## 2. 改动

- 只改训练步数：12 个模型 × LT/EQ/GT × 种子 1–3 × **10M**，共 108 个任务。legacy 奖励、不做奖励归一化，其余与 v4.3.1.6 相同。
- DQN 的 ε 衰减按总步数的比例（前 50%），因此变为前 5M 步衰减；PPO 无步数相关的调度。
- 新增 `src/paper_rl/greedy.py`（贪心基线，评估方式与 RL 相同）；`src/scripts/run_v4.3.1.10.py` 调度并生成 `report.md`（贪心 / 5M / 10M 三行对比）。
