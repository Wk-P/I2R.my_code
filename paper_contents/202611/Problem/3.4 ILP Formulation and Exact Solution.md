# 3.4 ILP Formulation and Exact Solution

## ILP 模型

变量 x_mn、y_n，目标为 3.2 的 AR，约束为 3.3 的 C1–C5。规模：MN + N 个二元变量，M + N + MN + KN 个约束。

## Dinkelbach 方法

AR = F/G 是分式。Dinkelbach 方法引入参数 ρ，每轮求解一个线性目标的参数化 ILP（约束不变）：

$$
\varphi(\rho) = \max_{(x, y)\ \text{可行}}\ \big[\, F(x) - \rho\, G(y) \,\big]
$$

由于 G(y) ≥ 1：

$$
F(x) - \rho\, G(y) > 0 \iff \text{AR}(x, y) > \rho,
\qquad
\varphi(\rho) > 0 \iff \rho < \text{AR}_{\text{ILP}},\qquad \varphi(\rho) = 0 \iff \rho = \text{AR}_{\text{ILP}}
$$

迭代：
1. ρ₀ = 0；
2. 用 CBC（PuLP，单线程）求解 φ(ρ_t)，要求状态为 Optimal，得到 (x_t, y_t)；
3. ρ_{t+1} = F(x_t) / G(y_t)；
4. |ρ_{t+1} − ρ_t| < 10⁻⁶ 时停止，输出 AR_ILP = ρ_{t+1}；否则回到第 2 步（最多 30 轮）。

每轮的解都可行，ρ_t 单调不降；可行解有限，迭代有限步终止。实测平均 3.06 轮收敛。

示意（3 个可行方案，AR 为 0.70 / 0.80 / 0.90）：

| 轮 | ρ | φ(ρ) | 返回方案 | 新 ρ |
|---|---|---|---|---|
| 1 | 0 | > 0 | AR 0.70 | 0.70 |
| 2 | 0.70 | > 0 | AR 0.90 | 0.90 |
| 3 | 0.90 | 0 | — | 停止，AR_ILP = 0.90 |

## 在本文中的用途

ILP 不参与 RL 训练，只用于：(1) 实例筛选——只保留 Optimal 的实例；(2) 评估——AR_ILP 作为 AR gap 的参照。
