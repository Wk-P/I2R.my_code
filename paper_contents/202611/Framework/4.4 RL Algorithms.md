# 4.4 RL Algorithms

所有算法用 Adam，学习率恒定，γ = 1，每个 run 2 × 10⁷ 步。PPO-M 用 sb3-contrib MaskablePPO，PPO-U/R/L 用 Stable-Baselines3 PPO；DQN/DDQN 基于 SB3 DQN。

## PPO

GAE 优势（λ_GAE = 0.95）：

$$
\delta_t = r_t + \gamma (1 - d_t)\, V(s_{t+1}) - V(s_t),\qquad
\hat A_t = \sum_{l \ge 0} (\gamma \lambda_{\text{GAE}})^l\, \delta_{t+l}
$$

裁剪目标与总损失：

$$
\rho_t = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\text{old}}}(a_t \mid s_t)},\qquad
L^{\text{clip}} = \mathbb{E}\big[\min\big(\rho_t \hat A_t,\ \text{clip}(\rho_t, 1-\epsilon, 1+\epsilon)\, \hat A_t\big)\big]
$$

$$
L = -L^{\text{clip}} + c_v\, \mathbb{E}\big[(V_\theta(s_t) - \hat R_t)^2\big] - c_e\, \mathbb{E}\big[\mathcal{H}(\pi_\theta(\cdot \mid s_t))\big]
$$

ε = 0.1，c_v = 0.5，c_e = 0.005。

## DQN

$$
y = r + \gamma (1 - d) \max_{a'} \bar Q(s', a'),\qquad \mathcal{L} = \mathbb{E}\big[\text{Huber}(Q(s, a) - y)\big]
$$

经验回放 + 目标网络 Q̄（硬同步）。

## DDQN

$$
y = r + \gamma (1 - d)\, \bar Q\big(s',\ \arg\max_{a'} Q(s', a')\big)
$$

在线网络选动作、目标网络估值，减小过估计。

Mask-DQN / Mask-DDQN：探索、贪心和 TD 目标中的 max / argmax 都只在 𝒜(s')（含 EXIT）内取：

$$
y_{\text{M-DQN}} = r + \gamma (1 - d) \max_{a' \in \mathcal{A}(s')} \bar Q(s', a'),\qquad
y_{\text{M-DDQN}} = r + \gamma (1 - d)\, \bar Q\big(s',\ \arg\max_{a' \in \mathcal{A}(s')} Q(s', a')\big)
$$

超参数见 5.1。

DQN(Deep Q-Network) 简介；DDQN(Double DQN) 简介；PPO(Proximal Policy Optimization) 简介

[Latex]

Reinforcement learning (RL) provides a framework for sequential decision-making, in which an agent learns a policy through interactions with an environment to maximize cumulative rewards. Deep reinforcement learning (DRL) extends this framework by integrating deep neural networks to approximate policies or value functions, enabling RL algorithms to address problems with complex state representations. Among existing DRL algorithms, Proximal Policy Optimization (PPO), Deep Q-Network (DQN), and Double Deep Q-Network (DDQN) represent two major learning approaches: policy-based and value-based learning.

**Proximal Policy Optimization (PPO)** is an on-policy, policy-gradient algorithm proposed by Schulman et al. \cite{schulman2017proximal}. PPO optimizes a parameterized policy using a clipped surrogate objective that limits excessively large policy updates. This mechanism improves training stability while maintaining a relatively simple optimization procedure. PPO is commonly implemented using an actor-critic architecture, in which the policy network determines action probabilities and the value network estimates expected returns.

**Deep Q-Network (DQN)** is an off-policy, value-based algorithm introduced by Mnih et al. \cite{mnih2015human}. DQN employs a deep neural network to approximate the action-value function, which estimates the expected cumulative reward associated with taking a particular action in a given state. To improve learning stability, DQN incorporates experience replay and a separate target network. These mechanisms allow previously collected transitions to be reused during training while reducing instability associated with rapidly changing target values.

**Double Deep Q-Network (DDQN)** was proposed by van Hasselt et al. \cite{vanhasselt2016deep} to address the overestimation of action values that can occur in DQN. In conventional DQN, the maximization operation used to compute target values may introduce a positive estimation bias. DDQN mitigates this issue by separating action selection from action evaluation, using the online network to select an action and the target network to estimate its value. This modification reduces overestimation bias without substantially changing the overall DQN framework.

These algorithms offer different approaches to learning sequential decision-making policies. PPO directly optimizes a stochastic policy, whereas DQN and DDQN learn action-value functions to guide action selection. Their different learning mechanisms provide a basis for evaluating the behavior and performance of deep reinforcement learning methods in sequential service placement problems.
