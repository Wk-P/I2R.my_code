# 4.3 Policy Network

关系感知 Transformer（relation-aware Transformer，代码 `src/paper_rl/graph_net.py`）。12 个变体共用。

## Token

T = 1 + N + M 个 token：

| token | 特征 |
|---|---|
| 全局（1） | AR_net；(M − t)/M；未部署需求和 / Σc_n；Σ max(free_n, 0) / Σc_n；［L：λ/(1+λ)］ |
| ECU n（N） | c_n / c_max；max(free_n, 0) / c_max；是否启用；对当前服务是否可行；已部署服务数 / M；load_n / c_n |
| 服务 k（M） | e_k / c_max；是否已部署；是否为当前服务；可容纳它的 ECU 数 / N；与其他未部署服务的冲突数 / M |

load_n 为 ECU n 上已部署需求和（含违约部署），free_n = c_n − load_n。输入：h⁰ = Linear_τ(f) + E_τ（τ 为 token 类型，E_τ 初始化为 0）；无位置编码。

## 关系偏置注意力

$$
\alpha^{(h)}_{ij} = \text{softmax}_j\!\Big( \frac{q^{(h)}_i \cdot k^{(h)}_j}{\sqrt{d/H}} + \sum_{r=1}^{4} w^{(\ell)}_{r,h}\, R_{r,ij} \Big)
$$

四种关系 R_r：(1) 未部署服务之间的冲突；(2) 服务部署在 ECU 上；(3) 未部署服务与 ECU 上已有服务冲突；(4) 未部署服务的需求 ≤ ECU 的 free。w 为每层、每头、每种关系的可学习标量，初始化为 0。

每层（Pre-LN）：

$$
x \leftarrow x + W_o\,[\alpha^{(h)} V^{(h)}]_{h},\qquad x \leftarrow x + \text{FF}(\text{LN}(x)),\qquad \text{FF}: d \to 2d \to d\ (\text{GELU})
$$

## 输出头

$$
s_n = \text{MLP}_{\text{ecu}}(h_n),\qquad
s_{\text{EXIT}} = w^\top h_{\text{glob}} + b,\qquad
V(s) = \text{MLP}_v\big([\,h_{\text{glob}},\ \overline{h}\,]\big)
$$

- PPO：π(a|s) = softmax(s_a)；M 中不可行动作 s_a 置为 −10⁹。
- DQN / DDQN：Q(s, n) = s_n，Q(s, EXIT) = s_EXIT（仅 M）。
- 对 ECU、服务的排列等变；token 数随 N、M 变化而参数不变，同一网络适用于不同规模。

## 超参数

| 项 | 值 |
|---|---|
| d / 头数 H / 层数 L | 128 / 4 / 3 |
| FF | 128 → 256 → 128，GELU |
| 参数量 | 450,227（L 为 450,355） |

## 设计动机

为了避免贪心模式带来的影响，不使用 MLP，改用 Transformer 为基础的结构感知网络（原 3.1 原稿）。事实依据：MLP 把所有数字拼成一维，无法直接表达 ECU–服务关系；前期 MLP 对照实验已放弃（记忆 drop-mlp），新实验不再含 MLP 对照。
