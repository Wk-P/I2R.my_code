# 5.2 Evaluation Metrics

- **测试模式**：用 20M 步的最终模型在固定测试集上做确定性推理（每步取 argmax），每个场景 5000 个实例。每个场景先对 3 个种子取平均，表中"平均"列为三个场景的算术平均；± 为种子间标准差。
- **AR**：只计合法放置的服务。
- **AR gap**：绝对 gap = ILP AR − AR；相对 gap = 1 − mean(AR) / mean(ILP AR)，在全部 5000 个实例上计算。下文未特别说明时，"gap"均指相对 gap。
- **违约率**：容量违约率、隐私违约率，各自统计出现至少一次该类违约的实例占比。两类可能同时出现在同一实例上，所以总违约率 ≤ 两者之和。
- **EXIT 率**（提前终止）：只有 Mask 有，指遇到死局时选择 EXIT 的实例占比。
- **时间消耗**：3×5000 个测试实例逐个计时，CPU 单线程（24 进程并行）。ILP 计时包含建模和全部 Dinkelbach 迭代；RL 计时为一个完整的确定性回合（reset、掩码、前向、step），用每个变体种子 1 的模型。加速比 = ILP 平均耗时 / RL 平均耗时。

公式（测试集 𝒯，|𝒯| = 5000；无违约完成集合 𝒯_ok = {i : M_v^{(i)} = M}）：

$$
\text{相对 AR gap} = 1 - \frac{\frac{1}{|\mathcal{T}|}\sum_{i} \text{AR}^{(i)}}{\frac{1}{|\mathcal{T}|}\sum_{i} \text{AR}_{\text{ILP}}^{(i)}},\qquad
\text{绝对 AR gap} = \overline{\text{AR}_{\text{ILP}}} - \overline{\text{AR}}
$$

$$
\text{容量违约率} = \frac{1}{|\mathcal{T}|}\sum_{i} \mathbb{1}\Big[\textstyle\sum_t v^{\text{cap}(i)}_t > 0\Big],\qquad
\text{隐私违约率} = \frac{1}{|\mathcal{T}|}\sum_{i} \mathbb{1}\Big[\textstyle\sum_t v^{\text{priv}(i)}_t > 0\Big]
$$

原稿（保留）：test 数据模式，测算时间消耗
