## 二、现行立论(一句话版本)

> **ILP负责离线、信息完备场景下的精确求解与基准标定,Safe RL负责ILP力所不及的在线、单步、不可回溯场景下的实时决策,二者是分工组合关系,不是替代关系;本文系统性检验这一"ILP定基准、Safe RL做在线执行"组合方案,在隐私冲突约束下能把在线决策做到多接近ILP给出的精确上界。**

写作时的两条硬性检查项(`立论说明.md`):
- 写到ILP的段落:语气必须是"肯定+划定适用边界",不能是"批评+被取代"。
- 写到RL/Safe RL做在线决策的段落:不能暗示"RL的存在让ILP变得不必要"。

## 三、核心实验结论总纲(以`论文概要3.md`第九节为准)

1. **在线、单步、不可回溯范式下,RL(含Safe RL)的AR与ILP最优解存在约0.10~0.12的稳定差距**(以lt场景为代表),10+轮独立实验(不同reward机制/steps预算/算法family)均收敛到同一区间,判定为决策范式本身的结构性上限,非奖励设计不充分。
2. **真正带来实质改善的是两类杠杆**:数据侧的场景多样性(200→2000场景池)、信号侧的奖励分级(二元→按AR连续分级)——⚠**此论断目前只在lt场景验证成立**,eq/gt从未做过同样的分级reward迁移实验(见十二.6节的核查结果),写正文时不能泛化到"三场景"。
3. **动作掩码不是学出有效策略的必要条件,reward是否分级才是**——证据来自ppo/dqn/ddqn这3个**完全不带任何约束机制**的算法(分级reward后成功率33%~37%)。⚠ppo_lagrangian(自带拉格朗日软约束)和ppo_opt(靠启发式修复兜底,非策略自主学会)的高成功率**不能**算作这一论点的证据,概要3的8.5节已把原来笼统的"27%~80%"重新拆分,避免过度归因。
4. **边界声明**:ILP是数学全局最优,RL/Safe RL本质上只能逼近、无法超越。

### 3.1 需要额外强调的两处易错点

- **"能否学出策略"与"能否守住隐私零违规"是两个独立问题,不能混为一谈**:reward分级解决前者(学习信号是否可用),动作掩码/拉格朗日对偶解决后者(部署时是否守住红线)。真无约束算法即便AR学得不错,隐私违规率仍有30%~40%,不可用于生产环境。
- **成功率与AR此消彼长**:策略要保证全部服务放置成功、不违规,必须把资源分散铺开留有余量,"成功"本身是以牺牲AR为代价换来的,不是能自然同步提升的两个指标。
