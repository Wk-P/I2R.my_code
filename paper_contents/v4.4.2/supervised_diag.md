# 监督诊断：网络能否从观测预测 ILP 最优动作（不训练 RL）

- 生成时间：2026-10-07 15:22:29；脚本 `scripts/diag_supervised.py`。
- 标签：每个实例的 ILP 最优分配（Dinkelbach）按需求降序回放；专家开一个空 ECU 时，同容量、合法的空 ECU 都算对（与 v4.4.2 BC 相同）。准确率 = 网络在合法动作中 argmax 落在标签集内的比例，按专家轨迹上的状态统计。
- 观测 A = 原观测（v4.3.8）；B = 原观测 + 未放置服务之间的冲突图（v4.3.4 的 `obs = conflict`，第 1 步即完整冲突图）。其余完全相同。
- 训练集：新生成的 p = 0.6 实例（同一生成器、不同随机种子）前 2000 / 10000 / 50000 个；测试集：v4.3.1.4 种子 1 的测试集 400 个（与 regret 诊断相同）。网络与 PPO 策略网络相同（MLP 256-256 tanh，带 mask 的 softmax），Adam、25000 步、batch 512、学习率 0.001 余弦衰减。
- 训练准确率在最多 3 万个训练样本上统计。「回放」= 用学到的网络在测试集上实际放置（取 argmax），报 EXIT 率与相对 gap（未 EXIT 实例，均值之比）。
- 参照：从零训练的 Mask PPO（v4.3.8 试跑）在自己轨迹上选中最优动作的比例（regret 诊断），第 1/2/3 步见表头下方。注意两者口径不同：这里的标签只是 ILP 的一个最优解（加同容量空 ECU），regret 诊断里的「最优」是所有 regret ≤ 1e-4 的动作，后者略宽。
