# v4.4.12 全局计划条件策略（global plan + sequential correction）

- 生成时间：2026-10-09 21:34:04
- 唯一改动：策略结构从反应式改为计划条件（`--plan`，`src/paper_rl/graph_net.PlanEncoder`）。一个独立的规划编码器（与主编码器结构相同、参数独立）读取实例的初始状态 s_0（由任意 s_t 清空分配、t 置 0 精确还原），生成服务 × ECU 计划矩阵 P_ij = ⟨W_s h_i(s_0), W_e h_j(s_0)⟩ / √d，整个 episode 内不变；每步 ECU logit = P[i_t, j] + 原有的逐步打分。W_e 零初始化，训练开始时 P ≡ 0、策略与基线完全相同。参数量 45 万 → 88 万（多出的全部是规划编码器）。
- 冒烟测试：零初始化时与普通网络 logits 完全相同；同一 episode 内 P 完全不变；随机 W_e 下 ECU 置换等变（误差 1.5e−6）；mask 与 EXIT 不变；策略采样无非法动作。
- 其余全部不变：EXIT 头、critic、ar_pen 奖励、MaskablePPO、lr 3e-4、熵系数 0.005、GAE λ = 0.95、γ = 1、需求降序、GPU、1M 步；不用 ILP、不用 BC，测试只做一次确定性 rollout。
- 基线 = v4.4.5 在 GPU 上训练的三种子基线，直接复用；新模型 manifest：`logs/v4.4.12/manifest.json`。
- 每个模型都在它自己训练种子的测试集上评估；相对 gap 先逐种子计算再取平均；表中为三种子均值 ± 样本标准差。
- 第 1–5 步 regret 与选中最优的比例来自 `src/scripts/diag_regret.py`（各种子测试集前 400 个实例）。噪声参照：同配置三种子 SD 0.4–0.7pp，同种子重跑可差 1.4–2.0pp；EQ 基线 10.2% 很可能偏高（多个变体为 9.4–9.5%）。
- 判断顺序（事先定好）：先看第 1–5 步 regret 是否下降、选中最优是否上升，再看多开 ECU 是否减少，最后看 gap。
