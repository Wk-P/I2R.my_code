# v4.3.9 观测加剩余服务×ECU 可行矩阵 F

在 v4.3.8（统一奖励、不提前结束、Maskable 带 EXIT）基础上，唯一改动是观测（`--obs feas`）：

- 末尾追加 M×N 矩阵 F：F[k, j] = 1 当且仅当服务 k 还没放、且现在放进 ECU j 既不超容量也不冲突；已放服务的行为 0。
- 动机：原观测第 13 组只给"未来服务 k 有几台 ECU 可去"（F 第 k 行的均值），看不出几个服务是否在争同一批 ECU；F 给出"具体是哪几台"。
- 原观测部分（87 / 77 / 102 维）不变，mask 位置不变。新维数：LT 237、EQ 177、GT 252。
- 试跑：`scripts/run_v4.3.9.py --pilot`，Maskable PPO / DQN × 3 场景 × 种子 1 × 1M 步；报告 `pilot_report.md` 中每个模型与 v4.3.8 试跑的同一模型（原观测）并排。
