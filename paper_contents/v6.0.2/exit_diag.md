# v6.0.2 Mask EXIT 归因诊断

- 生成时间 2026-10-22 14:36:07；脚本 `src/scripts/diag_exit_v6.py`；耗时 0.6 分钟；不训练。
- 模型：v6.0.0 的 Maskable 最终模型（PPO / DQN / DDQN，种子 1–3），在各自种子的 400 个测试实例上确定性回放；回放得到的 EXIT 实例数与 results.json 逐 run 核对一致。
- 对每个 EXIT 实例，固定轨迹的前 t 步放置：
  - **t_inf**：ILP 判定剩余部分已无可行解的最小 t，即让实例变成无解的那一步；
  - **t_cheap**：某个尚未放置的服务已没有任何合法 ECU 的最小 t（只看当前状态的一步必要条件）；
  - **t_exit**：EXIT 前已放置的服务数。三者满足 t_inf ≤ t_cheap ≤ t_exit。
- **潜伏步数** = t_exit − t_inf：实例已经无解、但策略还在继续放置的步数。**可见步数** = t_exit − t_cheap。
