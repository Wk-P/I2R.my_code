# v4.3.3 — 推理时采样 K 个解取最好（best-of-K）

新的次版本（tag `v4.3.3`）。不重新训练，只做评估。

## 1. 动机

v4.3.1.x 的所有奖励变体下，RL 的 AR gap（ILP AR − AR）都在 0.15~0.17，与贪心基线（`src/paper_rl/greedy.py`）持平或略大。本版本是诊断：**PPO 策略的概率分布里，是否包含比确定性输出、也比贪心更好的解？**
- 能明显超过贪心：模型"知道"更好的解，加大训练 / 换网络有意义，论文也可报告"时间换质量"的曲线。
- 采样 64 次也几乎不涨：策略本身困在贪心水平，单换网络大概率不够。

## 2. 方法

- 模型：v4.3.1.6 的 PPO 系列 4 个模型 × 3 场景 × 种子 1–3（5M）；对照：随机贪心。
- 每个测试实例采样 64 个解：第 1 个是确定性输出 / 纯贪心，其余按策略概率采样（Maskable-PPO 带掩码）/ 每步以 0.2 概率随机选一个可行 ECU。K = 1、4、16、64 取前 K 个。
- **公平性**：挑选只用解本身能算出的量（先成功，再 AR 最高），最优 AR 只用于最后计分；贪心给同样的 K；耗时按 K 倍如实报告，与 ILP 放在同一时间尺度比较。
- DQN 系列不做：Q 值没有自然的采样分布。
- 脚本：`src/scripts/eval_v4.3.3.py`；输出 `raw.jsonl`、`report.md`。
